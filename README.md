# MaxHack — Modo estudio v1.1

Versión de estudio del MVP de MaxHack.

## Cambios principales
- La app funciona únicamente en modo estudio.
- El orden de preguntas y alternativas se mezcla automáticamente en cada sesión.
- El usuario recibe un aviso explicando que el banco puede mostrar preguntas diferentes en futuros intentos.
- Se eliminaron las letras A/B/C/D visibles en las alternativas.
- En la revisión final se muestran los textos de las respuestas, no las letras internas.
- Se corrigió el mensaje cuando el resultado es 100%.

## Archivos
- `index.html`
- `styles.css`
- `app.js`
- `preguntas.json`

## Para actualizar GitHub Pages
Reemplaza en la raíz del repositorio los archivos `index.html`, `styles.css` y `app.js`. El archivo `preguntas.json` puede mantenerse si ya contiene el mismo banco de preguntas.
